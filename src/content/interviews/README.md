# Owner interviews

Add `<property-id>.md` only after a real interview. Frontmatter must include `review_status: approved` and `consent: granted` for display. Record interview date, interviewee, reviewer and consent evidence internally. Do not add invented quotations. Markdown HTML, images and links are disabled in the renderer. The property itself must pass the live publication review.

Example frontmatter (not a publishable interview):

```yaml
property_id: live-property-id
review_status: draft
consent: pending
interviewed_at: YYYY-MM-DD
```
