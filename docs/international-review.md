## 確認方法と公開境界

`npm run dev:review` または `node scripts/site.mjs dev --mode review --port 4322` を実行し、`http://127.0.0.1:4322/ko/`、`http://127.0.0.1:4322/zh-cn/` を開く。英語・日本語ページのヘッダーに韓国語・中国語へのリンクを追加し、4言語の対応するページを相互に移動できる。宿記事や地域ページでも同じ対象への切替を維持する。リンク追加はレビュー環境のみ。

新規2言語は `review` モードでのみ生成する。デモ・本番では生成せず、サイトマップにも追加しない。全ページに草稿表示と `noindex,nofollow` を付ける。2026-10-27の利用者によるリンク追加・Commit・Pushの指示を根拠に、日本語UIのリンク追加と折り返しに限定して承認記録を更新。日本語5記事は変更していない。韓国語・中国語の翻訳公開承認とは区別する。

公開する場合は、翻訳・施設名表記・画面の人による確認後、各言語の承認記録と内容ハッシュによる公開判定を別途実装し、本番の言語切替・hreflang・サイトマップへ接続する必要がある。今回の利用者指示はリンク追加後のCommit・Pushまで。送信先は `codex/korean-chinese-pages`。mainへのマージ・本番公開は今回行わない。
